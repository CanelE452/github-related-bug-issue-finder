# 관찰과 경쟁 설명

이 문서는 저장된 실제 순위·토큰·범위 관찰입니다. 관련성 등급, 현재 버그 재현 및 해결 성공은 미판정입니다.

## 수집·필터 위치

- 역사 원문 OpenCV #17687 / Transformers #24694: 최신 20페이지의 C_raw와 C_bug 모두에 없음. 원문을 개별 조회했지만 인덱스에 추가하지 않음.
- O-S2 #30090(온라인 문서 누락), T-E2 #48346(FP8 예외), T-C2 #48315(재개 학습 종료 오류): C_raw에 있고 C_bug에는 없음. 세 과제를 평가 실행에서 제외하지 않음. 문서 문제는 앱의 Bug 대상 정의와 다를 수도 있어 사람이 관련성을 확인해야 함.
- 수집은 저장소마다 API 항목 2,000개(PR 포함). PR을 제외하면 OpenCV 387개, Transformers 390개만 남음. 20페이지는 Issue 2,000개를 의미하지 않으며 전체 저장소 조사도 아님.

## 어휘 무일치

BM25의 정상적인 `no_lexical_match`는 다음 5회입니다. 실행 예외가 아니며 가짜 0점 관련성 판정으로 바꾸지 않았습니다.

| 입력 | 범위 |
|---|---|
| T-E1:A_ko_symptom | C_raw, C_bug |
| T-E2:A_ko_symptom | C_bug |
| T-C1:A_ko_symptom | C_raw, C_bug |

한국어 질의의 `Gemma4로`, `Gemma4에서`, `generate를`은 현재 단어 토큰화에서 영어 원문의 `Gemma4`, `generate`와 그대로 일치하지 않을 수 있습니다. 독립적인 한국어 형태 분석을 넣지 않은 기존 구현의 관찰입니다. 의미 검색이 참고 원문을 회수한 경우라도 다른 결과의 실제 관련성까지 확인한 것은 아닙니다.

## 결합 순위 하락

O-E1:A_ko_symptom의 참고 원문은 [OpenCV #29350](https://github.com/opencv/opencv/issues/29350)입니다.

| 범위 | BM25 원문 순위 | 의미 검색 원문 순위 | Hybrid 원문 순위 |
|---|---:|---:|---:|
| C_raw | 103 | 2 | 20 |
| C_bug | 73 | 2 | 25 |

원문은 수집/필터/의미 후보에서 빠진 것이 아닙니다. BM25 상위 50개 밖이므로 RRF에서 의미 검색 한 쪽의 `1/(60+2)`만 받습니다. 두 방식에 동시에 나타나는 문서가 원문보다 높은 합산 점수를 받을 수 있습니다. 이는 이번 결합 코드/실제 순위가 설명하는 현상이며, 원문과 경쟁 문서의 직접 관련성을 판정하기 전에는 잘못된 검색이라고 확정하지 않습니다. Top-20 밖의 Hybrid 문서는 전체 corpus 순위로 만들어 내지 않았습니다.

## 입력 정보 추가와 언어

C_raw의 한국어 증상 A에서 참고 원문 Top-5 회수는 BM25 8/12, 의미 검색 9/12, Hybrid 10/12입니다. 환경/오류를 추가한 B와 같은 정보를 영어로 작성한 C는 세 방법 모두 참고 원문 12/12를 회수했습니다. 이 수치는 **참고 원문 회수 진단**이며 Hit@5나 해결 성공률이 아닙니다.

경쟁 설명은 다음과 같습니다.

- B는 오류 문자열, 함수/모델 식별자, 버전 등 원문에 실제 있는 구별 단서를 추가합니다. 정보 추가와 어휘 일치가 함께 바뀌므로 순수 의미 이해의 개선으로 해석할 수 없습니다.
- 질의 작성자가 원문을 읽었고 이번 표본을 C_raw에서 선택했습니다. 실제 사용자 질의와 무작위 외부 문제에 일반화할 수 없습니다.
- B↔C의 번역 동등성은 아직 사람 검토 전입니다. 두 입력의 결과가 같다고 한국어·영어 품질 차이가 없다고 결론 내리지 않습니다.
- 문서의 최대 유사도 구간이 실제 증상인지 환경/템플릿인지 사람 검토 전입니다. 긴 본문에서 환경 구간만 매칭되는 대안 설명이 남습니다.

계약과 차이는 후보 49개 검토(상한 48개보다 1개 초과), 잠정 유형 분류, E1/E2/E3/실사용 비교 미실행입니다. 부족한 검증을 완료라고 표시하지 않았습니다. 다음 단계는 보고서의 세 검토 우선순위를 따르며 이번 표본으로 모델·RRF 상수를 튜닝하지 않습니다.
